# Run Bun! — Almanac artwork

Read the shared CardSets/GEN.md first. This supplement records Almanac-specific direction; current user instructions take precedence. It grants no code-edit or further-art-production permission.

## Standalone illustrations

Create rectangular scene artwork ONLY: no baked lettering, frame, border, banner, nameplate or description panel. The renderer supplies the approved Frame Almanac and typography separately. Inspect the current frame and installed Day of the Bun, Dog, Dragon and Reaper images directly for composition and rendering quality.

Compose a strong, distinct creature focal point for the central opening. Leave headroom and clearance for inward ornaments; extend coherent scenery behind the frame edges. A perfect silhouette cutout is unnecessary because the opaque textured frame body masks the surrounding scene. Existing day images are approximately 1582 × 994; retain their landscape composition and detailed finish.

Use beautiful, richly colored Victorian-steampunk settings and purposeful mechanisms. Keep foreground and background sharp: no blur, bokeh or depth-of-field softening. Check anatomy, grips, support and mechanical connections before installation.

Character variety is imperative. Use references for style and established anatomy, not to clone the same male/female Bun or Dog across scenes. Vary individuals, fur, clothing, expression, pose and setting while retaining Run Bun identity. Dogs are demonic: menacing eyes, fangs and canine fur/anatomy; horns are optional and fur must not glow. Wolf, Ram and Hart are actual animals; do not add Angel visual references.

## Separate reusable frame and lettering

Preserve the approved enlarged frame scale, layout, tall title areas and generous art opening. Keep the rounded rectangular description interior completely clear; the hourglass stays below it. The thematic textured body must be continuous beneath and between ornaments, with a finished rounded outer contour. Transparency belongs only outside that contour and in the art opening, not in fragmented gaps through the frame body. Use Frame Lure, Nasty, Nice and Panic as construction references when explicitly authorized to edit a frame.

Render “Day of the” in the upper curved banner and the creature name in the lower plaque. Almanac Name (ALMANACNAME, size 42) uses IM FELL English SC for the curved upper banner. Almanac Name Large (ALMANACNAMELARGE, size 60) inherits its appearance and supplies the lower creature name. Do not bake typography into illustration files.

## Data, scope and preservation

Use exact filenames Day of the [Creature].png and matching CSV Names, Type Almanac, Deck Almanac. Leave Description and Flavor blank until supplied; do not invent mechanics. The current list of 19 unbuilt concepts is Ideas.txt. Interval is outside the 23-day list: Type Interval, Deck Clockwork, with its full-card image in Images/Clockwork and the separate Clockwork back.

Preserve every generated source and revision. Before replacing installed artwork, preserve and verify its prior version in the existing Backups location; keep alternate versions out of the active illustration folder. Follow shared source-preservation rules and current explicit user exceptions. Do not overwrite concurrent user edits. Report file checks separately from Studio visual validation, which the user performs.
